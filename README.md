# Entropia Planet Helper

An offline, read-only Windows guide for **Entropia Universe**. Pick the destination you are on and it shows the best next unlocks, missions and dailies, ranked, with steps, costs, cooldowns, waypoints and the sources behind every entry.

Unofficial fan project. Not affiliated with or endorsed by MindArk PE AB or any Planet Partner. Entropia Universe is a trademark of MindArk PE AB. All game facts here are summarised in our own words with links to the original pages; no game art or copied guide text is included.

## Safety: what it does and does not do

- **Does:** show curated, cited data shipped in `data/planets/`, and remember what *you* tick off in a local file.
- **Does not:** read the game, its memory, its logs or chat; hook processes; press keys or click; automate missions; log into anything; or send anything over the network. There is no telemetry. The only network action is when *you* click a source link, which opens your own browser.
- **Planet choice is manual.** There is no documented, trustworthy local signal that says which planet you are on, so the app does not guess. You pick it, and it remembers your last choice.
- **Progress file:** `%LOCALAPPDATA%\entropia-planet-helper\progress.json` (outside the repo). Delete it to start over. If it is ever damaged the app keeps a `progress.corrupt-*.json` copy and starts clean.

## Install and run

Needs Windows and Python 3.10+ with Tk (the standard python.org / Microsoft Store Python includes it). No other dependencies.

```powershell
git clone https://github.com/suttonwilliamd/entropia-planet-helper.git
cd entropia-planet-helper
pythonw -m planet_helper --planet aris        # opens on ARIS; switch planets in the app
python  -m planet_helper --check               # validate data, no window
powershell -ExecutionPolicy Bypass -File scripts\install_shortcut.ps1 -Planet aris   # Desktop shortcut
```

`--planet <id>` only chooses the starting destination; you can change it in the app at any time. Ids: see `python -m planet_helper --check`.

**Updating:** `git pull`. Your progress is stored outside the repo and is kept.

**Releases:** each push to `main` is a tested checkpoint. To make a release, tag a tested commit (`git tag v0.x.y && git push --tags`) and point users at the tag; no binaries are built or uploaded.

## Using it

- **Destination** (top left): the planet/moon/area you are on. Inactive or unverified places are labelled.
- **Your stage here:** Arrival, Early, Mid or Late. Ranking favours your stage and pushes far-ahead content down.
- **Show:** *Next actions* (ready now, best first), *Everything*, *Cooling down*, *Blocked* (needs something first) or *Done*.
- **Type / Search (Ctrl+F):** narrow by kind (daily, unlock, mission chain...) or words. Esc clears the search.
- **Budget mode:** weights cost more heavily, for low-budget play.
- **Detail pane:** why it is ranked there, steps, rewards, cost and markup notes, currencies earned/spent/kept, prerequisites (✔/✗), limits, cooldown, waypoints with a **Copy** button (paste `/wp [...]` into game chat yourself), warnings and dated sources.
- **Mark done (D) / Ready again / Undo:** Ctrl+ and Ctrl- change text size.

### How ranking works

`score = (0.40·value + 0.35·budget + 0.25·quickness) / 5 × confidence`, where value, budget and quickness are 1–5 ratings given per activity with a written rationale, and confidence is 1.0 / 0.85 / 0.6 for high / medium / low evidence. Same stage as you: +10%. Each stage ahead of you: −25%. Budget mode uses 0.25 / 0.55 / 0.20. Activities whose prerequisites you have not ticked go to *Blocked*; ones on cooldown go to *Cooling down*. Rankings are judgement calls from cited evidence, not promises: **nothing here guarantees profit**, markup changes constantly, and Entropia costs real money.

### Cooldowns and resets (exact meaning)

The app cannot see the game, so timers run from the moment **you** press *Mark done*.

- **One-time:** stays done. *Undo* reverses it.
- **Rolling N h:** ready again N hours after you marked it.
- **Fixed reset:** if the source gives a UTC hour, it resets automatically at the next such hour; otherwise press *Ready again* when the game shows it is available.
- **Unknown:** stays "cooling down" until you press *Ready again*.
- *Ready again* clears the timer but keeps the item counted as done for prerequisites. *Undo* removes the record entirely.
